# Look Out the Window

A web application for searching and viewing videos from different cities at different times of day.

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Design

## Features

- Search videos by city
- Filter videos by time of day
- Dynamic video cards
- Video playback
- Loading and error states
